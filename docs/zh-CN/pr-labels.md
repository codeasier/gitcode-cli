# PR 标签编辑

`gc pr edit NUMBER --add-label "help wanted,bug" --remove-label "old"`
使用 GitCode 专用标签端点：添加为 POST JSON 数组，删除为带单个 URL 编码名称的
DELETE，不再发送不受支持的 `unset_labels` 或用空字符串替换全部标签。
可删除最后一个标签，同时保留无关标签。

逗号分隔输入会去重；空段、单独的 `.` / `..`、控制字符，以及同一标签同时添加和
删除均在写入前拒绝。此 CLI 语法无法表示名称内部包含逗号的单个标签。
已存在的添加和不存在的删除为成功无操作。

操作前核验 PR 编号/id 和标签身份；最终读回核验目标成员关系、删除结果以及无关
标签身份不变，允许并发新增其他标签。与人员、里程碑混合编辑共用最终确认快照。
多次调用并非事务，后续失败时之前的修改可能已生效；不会自动重试或回滚写入。
重试前请先检查该 PR。任何读回后仍可能发生服务端并发变化。

## 验证边界

单测及严格隔离凭据的 HTTP 契约覆盖请求形状和失败路径；fixture 是合成示例，
不是实录。另行获授权后，可在一次性 PR 上验证：添加时保留其他标签、逐个删除及
删除最后一个、特殊字符/空格/中文名称、重复无操作、混合标题/人员/里程碑、并发
新增无关标签，以及两次删除中第二次失败。确认不重复写、不误报成功、不丢失无关
标签；失败重试前核对远端状态。本变更不声明已完成 live 验收，不猜测里程碑清除
契约，也不授权审批、发布或部署。
